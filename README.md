# Adel Mounir Portfolio

A production-grade, highly optimized, bilingual developer portfolio showcasing enterprise systems and automated software solutions. Engineered with Next.js, React, Tailwind CSS, and Framer Motion.

## Overview

This portfolio serves as a central hub demonstrating real-world software engineering projects. It is built focusing on page speed, accessibility, clean responsive layout, and localization to present work effectively to both domestic and international markets.

## Core Features

- Bilingual Architecture: Full internationalization support with localized routing (English and Arabic RTL layout).
- Responsive Engineering: Fluid layout system adaptable to desktop, tablet, and mobile displays.
- Visual Mechanics: Clean UI micro-animations and physics-based interactions for improved engagement.
- Adaptable Theming: Integrated dark and light display modes reflecting user system preferences.

## Local Development

### System Requirements

- Node.js 18.0.0 or higher
- npm, yarn, or pnpm package manager

### Initial Setup

1. Retrieve the codebase:
   ```bash
   git clone https://github.com/Amounir930/adel.git
   ```

2. Access the project directory:
   ```bash
   cd Adel
   ```

3. Resolve dependencies:
   ```bash
   npm install
   ```

### Execution

Execute the local development environment:
```bash
npm run dev
```

The application will be accessible at `http://localhost:3000`.

## Distribution and Deployment

This project is prepared for deployment to static hosting systems (via export builds) or serverless cloud runtimes such as Vercel.
